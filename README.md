# Basic Bank Management System

A simple Bank Management System built using Python and Object-Oriented Programming (OOP).

## Features

- View bank account details
- Check account balance
- Deposit/Credit money
- Withdraw/Debit money
- Basic input validation
- Uses a single account named Ankush

## Technologies Used

- Python
- Object-Oriented Programming (OOP)

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in PowerShell or Command Prompt.
4. Run the Python file:

```bash
python main.py
